# CardFlux

Django-проект для магазина цифровых товаров (плагины, примеры кода и т.п.).

## Технологии
- Python
- Django 5+
- Bootstrap 5 (через CDN)

## Установка и запуск

1. Создать и активировать виртуальное окружение:
   ```bash
   python -m venv venv
   # Windows PowerShell:
   .\venv\Scripts\Activate.ps1
   
2. Установить зависимости:
bash
pip install -r requirements.txt

3. Запустить сервер:
bash
python manage.py runserver

4. Открыть в браузере: http://127.0.0.1:8000/
