CardFlux:
Интернет-магазин товаров для ремонта и освещения на Django. Проект реализует базовую функциональность: маршрутизацию, шаблоны страниц, обработку форм и вывод данных.

О проекте
CardFlux — это современный интернет-магазин, построенный с использованием Django. Проект включает в себя:

Полноценную систему маршрутизации
Адаптивный дизайн на Bootstrap
Формы обратной связи
Систему обработки данных

Используемые технологии
Python — основной язык разработки
Django 5.2.18 — веб-фреймворк
Bootstrap 5 — для адаптивного дизайна (подключен через CDN)
HTML5/CSS3 — базовая вёрстка

Функционал
Главная страница — витрина товаров и категорий
Страница контактов — форма обратной связи и контактная информация
Система форм — валидация и обработка данных
Уведомления — сообщения об успешной отправке 

Установка и запуск
1. Создание окружения
Для Windows:

python -m venv venv
venv\Scripts\activate
Для macOS/Linux:

python3 -m venv venv
source venv/bin/activate

2. Установка зависимостей

pip install -r requirements.txt

3. Запуск проекта

python manage.py migrate
python manage.py runserver
